Runner.io

영토 점령을 통한 포인트 경쟁과 AI 러닝 분석을 구현한 러닝 모바일 앱

Runner.io는 러닝을 지도 위의 경로, 포인트, 랭킹, 영토 점령으로 연결하고 AI 리포트로 운동 결과를 해석한다.

개발 배경

기존 러닝 기록은 운동 후 숫자 확인에 머물러, 사용자가 다시 뛰게 만드는 경쟁성과 공간 피드백이 약하다.

  • 반복 사용: 기록만 보여주는 앱보다 다시 뛰게 만드는 보상 구조가 필요했다.
  • 지도 경험: 내가 뛴 경로가 지도 위 성취로 남는 화면이 필요했다.
  • 결과 해석: 페이스와 구간 데이터를 사용자가 이해하기 쉽게 정리해야 했다.

개발 목표

GPS 경로 → 영토 점령 → 포인트/랭킹 경쟁 → AI 리포트 회고 흐름을 실제 앱 기능으로 연결한다.
