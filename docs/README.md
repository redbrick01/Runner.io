# `docs/` 문서 인덱스

이 폴더는 프로젝트 설명, 구조 점검, 테스트 결과, 제출 보고서 산출물을 보관한다.

## 문서

- `PROJECT_STRUCTURE.md`: 전체 폴더 구조, 앱/백엔드/네이티브 역할, 데이터 흐름
- `PRE_GIT_CHECKLIST.md`: Git 업로드 전 제외 파일, 민감 정보, 검증 명령
- `test_plan_and_results.md`: 테스트 계획, 수행 결과, 발견/수정 사항
- `final_midterm_report_en.txt`, `*.docx`: 중간보고서/제출용 문서 산출물

## 관리 기준

- 개발자가 새로 온 경우 `README.md` -> `docs/PROJECT_STRUCTURE.md` -> `docs/PRE_GIT_CHECKLIST.md` 순서로 읽으면 된다.
- 테스트나 배포 결과가 바뀌면 `test_plan_and_results.md`를 갱신한다.
- 중복 `.docx` 복사본은 정리했고, 남은 보고서 파일은 제출 산출물로 유지한다.
