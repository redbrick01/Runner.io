# Badge Assets

Generated badge design assets for Runner.io achievements.

## Files

- `generated/runner_badges_board.png`: full 4x2 badge design board
- `generated/icons/`: badge-only crops without labels, intended for in-app UI
- `generated/tiles/`: badge crops with Korean labels, intended for docs/mockups

## Badge Names

| File | Label |
|---|---|
| `first_run.png` | 첫 러닝 |
| `first_5km.png` | 첫 5km |
| `seven_day_streak.png` | 7일 연속 |
| `total_100km.png` | 누적 100km |
| `territory_pioneer.png` | 영토 개척자 |
| `territory_ruler.png` | 영토 지배자 |
| `best_pace.png` | 최고 페이스 |
| `monthly_10_runs.png` | 월 10회 |

The `tiles/` directory uses the same base names with `_tile` suffix.
