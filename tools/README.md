# `tools/`

## 역할

`tools/`는 프로젝트 개발/배포 과정에서 사용하는 보조 스크립트를 보관합니다. 현재는 앱 아이콘 리소스 생성을 위한 Swift 스크립트가 포함되어 있습니다.

## 주요 파일

| 파일 | 설명 |
|---|---|
| `generate_app_icon.swift` | `assets/app_icon/app_icon_ios_1024.png`를 기반으로 플랫폼별 앱 아이콘 크기를 생성하는 Swift 스크립트 |

## 동작 흐름

```text
원본 아이콘 준비
-> generate_app_icon.swift 실행
-> 플랫폼별 아이콘 파일 생성
-> 각 platform runner에서 아이콘 사용
```

## 관련 기능

- 앱 아이콘 리소스 생성
- 배포 전 리소스 정리

## 참고 사항

- 새 도구를 추가할 때는 입력 파일, 출력 경로, 실행 방법, 생성되는 파일의 Git 관리 여부를 이 문서에 함께 기록해야 합니다.
- 스크립트 실행으로 생성되는 플랫폼별 아이콘은 실제 앱에서 참조되는 경로와 일치해야 합니다.
